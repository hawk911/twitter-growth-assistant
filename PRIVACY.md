Privacy Policy

This is a private personal application operated by one individual for managing and analyzing a single X account.
The application may access the operator's X profile, posts, public engagement metrics, mentions, and a limited number of public posts from selected public accounts.
The application does not request users' email addresses, sell personal data, share X data with third parties, perform sensitive profiling, or provide a public database of X content.
Access to the application and stored data is restricted to the operator. Only the minimum data required for content research, analytics, deduplication, and account management is retained. Data is de
leted when it is no longer required and applicable X deletion requirements are respected.
